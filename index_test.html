Sideloading Instructions

  1. Download: Tap the download button from your Android device browser via GitHub Pages.
  2. Allow Installation: If prompted by Android security, enable "Install from unknown sources" for your browser.
  3. Configure Server: Open Aptis Mobile, enter your lab server IP address and port `5000`.
  4. Monitor: Enjoy real-time touch-to-set target crosshairs and health scores right at the optical table.
