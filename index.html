Deployment Guide

NixOS Firewall & Server Execution

To allow mobile devices and remote workstations on your local subnet to access the Aptis telemetry server, configure port 5000 in your NixOS configuration.

  • Add port 5000 to configuration.nix firewall
  • Run `sudo nixos-rebuild switch`
  • Launch `python stream_server.py`
bash — /etc/nixos/configuration.nix
NixOS 24.05
# 1. Open port 5000 in firewall configuration 
networking.firewall = {
  enable = true;
  allowedTCPPorts = [ 5000 ];
};
# 2. Rebuild system & run the telemetry server

$ sudo nixos-rebuild switch

$ source venv/bin/activate

$ python stream_server.py

Running on http://0.0.0.0:5000
